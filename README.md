# Video & Image Kiosk App (Android)

An Android **kiosk-style media player application** that automatically plays **videos and images in a continuous loop** from local device storage.  
This app is designed for **digital signage**, **advertising displays**, **exhibitions**, and **self-service kiosks**.

---

## 📱 Features

- ▶️ Plays **videos and images** from local storage
- 🔁 Continuous **loop playback**
- 🖼 Supports multiple media formats (images & videos)
- 📂 Automatically scans a predefined storage folder
- 🚫 Shows alert if no media files are found
- 🔐 Handles **runtime storage permissions**
- ⚡ Optimized for **kiosk / unattended mode**
